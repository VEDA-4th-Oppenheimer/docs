## CMD 번호 할당표

> **규칙: 번호를 쓰려면 코드보다 이 표에 먼저 행을 추가합니다.**
> 두 사람이 같은 번호를 쓰면 각자 로컬에선 잘 되다가 합칠 때 깨지고,
> 원인 찾는 데 한참 걸립니다.

**대역**: `0x00~0x7F` = RPI → STM32 (요청) · `0x80~0xFF` = STM32 → RPI (응답/보고)
